# 企画の内容（重要）

このプロジェクトは、ゲームを作ること自体が目的ではなく
とりあえず、一旦ゲームが動く形になったら、AI仮想人格キャラと一緒にゲームプレイをして
AIにゲームの改良点を出してもらって、AIの考えでゲームを成長させていくという内容になります
その様子をYoutube等動画サイトで公開する予定です

# プロジェクトの進め方

## 初期実装フェーズ

### 初期実装１

- ゲームの骨格を作る
- 環境設定、pygameのインストール
- 自キャラは１人固定、弾を打ち続ける。敵はランダム登場
- この段階では、パワーアップアイテムやボス敵は無し。味方は一人。敵は雑魚１のみ。

### 初期実装２

- 味方のパワーアップを実装
- パワーアップアイテムをランダムに混ぜる
- パワーアップアイテムを取って、味方の数が増えたり攻撃力が増えたりする処理

### 初期実装３

- ステージ中に登場する敵やパワーアップアイテムを、ファイルで指定できるようにする
- ステージの概念をつけ、ステージクリアの処理をつける
- 複数ステージを続けてプレイできるようにする

## 配信フェーズ

- プレイヤーとAIがゲームをプレイ
- その様子を配信
- 改良点をAIキャラに提案させる
- 次回配信までに改良できるものは改良する
の繰り返しになります。

ここから後の改良はAI次第
AI人格はかわいい女性キャラなので、画面全体がピンクになったりお花畑になったりする可能性があります
